# cc-debrief

## 0.2.0

### Minor Changes

- Coaching and recap: per-session findings ranked by cost, with a digest card on the Overview; opt-in AI session
  reviews with a cost estimate, feedback and "Review all"; repeated-work detection with skill drafts you edit and
  install by click; `cc-debrief recap` and the Recap view, with hidden repos and opt-in AI polish. Tracker calls no
  longer resume your session: they send the stored turns with all tools and MCP servers off.
- Activity, costs and replay: 90-day and all-time ranges; Activity view (365-day heatmap, streaks, hours, weekdays); Costs view (per
  day by model, by repo, per model, cache savings, run rate vs plan prices); monthly budget band and digest item; spend
  spike digest rule; pricing overrides; full session replay with Markdown, filters and find; repo trends and memory
  files; tool categories, feature adoption and version history; agents, commands, output styles, rules and workflows in
  the inventory (migration 009); Tasks & plans view; Overview donuts; Ctrl/Cmd-K palette and keyboard navigation; and
  `cc-debrief digest`.
